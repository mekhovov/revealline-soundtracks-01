# Groove-first metal auditions

Four newly published recordings selected after YannZ's **Pixel Damnation** and **Revenge's Waiting**
were identified as closer to RevealLine's required groove. The independent
comparisons are **Soul Ripper** and **Achilles**. **German Industrial Metal** was
retained in the intake evidence but is not republished because the same recording
and bytes already exist in the [core archive](../core-20260924/).

Four newly published recordings; 19101744 delivery MP3 bytes. **Revenge's Waiting**
is a 48-second 12/8 boss cue and does not count as a full gameplay composition.
All native files and normalized derivatives passed complete decoding and technical
measurement. Full listening, repeated-loop fatigue, transitions, warning audibility,
style review and game admission remain pending.

Click a song to play. Pause/Resume, Next, shuffle and repeat-all use the unchanged
archive player. Credits, source links, licences and modification notices are in
CREDITS.md. Content ID status is unknown, so all four remain excluded from
Recording mode. This is a listening preview, not a gameplay-video claim-free assurance.
