# Purgatory vol. 3 rhythmic-metal audition intake

This source-only intake prepares four exact David KBD recordings requested for
the next heavier and more rhythmic metal comparison. It publishes no audio,
grants no listening approval, admits no recording into the game, changes no
default and leaves every track ineligible for Recording mode.

The creator page publishes the pack under CC BY 4.0, lists the eight complete
OGG recordings separately from 17 mini-loops, describes the music as extreme
metal for bosses and action games, and names Depised Icon and Dark Tranquillity
as inspirations. The four selected free uploads are:

## Fail-closed preparation

- The source is bound to its origin, slug, game ID `3755088`, normalized
  description hash, CC BY badge, direct licence link, upload IDs and visible
  filenames. Changed terms or files stop before media acquisition.
- Cookies, CSRF values, private download keys and signed URLs stay ephemeral.
- Hosted preparation retains exact native bytes, completely decodes each OGG,
  measures source loudness, produces a 256 kbps MP3 derivative at the existing
  loudness/peak targets, fully decodes it and checks current public native and
  delivery hashes plus normalized titles for duplicates.
- Source durations are short complete action pieces, not mini-loops. The batch
  uses a reviewed 100-second floor rather than pretending they meet the longer
  three-minute arrangement target.
- Content ID, vocals, explicit content, full-track listening, transitions,
  warning audibility and game suitability remain pending.
