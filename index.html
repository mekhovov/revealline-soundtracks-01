Preview prerelease · manual import. Choose from 15 packs containing these 70 creator recordings. Each includes credited MP3s and one playlist set to shuffle and repeat all. Musical review is pending; these are not approved built-in game albums.

Requires RevealLine v0.78.0 or newer. If your game has no Add album file to draft action, use the individual MP3 downloads until the new framework is available.

  1. Download a pack below. In the game, open Settings → Music library & playlists and keep a backup of any existing library.
  2. Choose the pack under Soundtrack recovery or album file (.rlsound), then select Add album file to draft → Save all changes.
  3. Choose its playlist, select Save & use playlist, turn sound on and press Play music if paused.
  4. To combine installed styles, choose My mix, select the genres and use Save & use music selection. This clears the explicit playlist selection.

Choose a subset. All 70 recordings use 338.54 MiB of audio, exceeding the 256 MiB shared media budget before other saved media. The library also allows 123 custom tracks and 26 custom playlists. Sizes below include pack metadata; Save checks your actual available space.

If an older preview copy is already installed, keep it and its backup: changed credits can trigger an identity conflict. Do not use replacement import just to add an album. Keep downloaded packs as a backup.
