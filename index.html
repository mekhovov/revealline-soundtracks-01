CATALOGUE INTAKE

Add an MP3 once; play it everywhere

Select one MP3 or one folder. The repository automation discovers songs, reads available ID3 metadata, hashes and credits every recording, rebuilds this catalogue, runs verification and can open the pull request. The generated feed is used by this page and RevealLine’s in-game archive browser.

  1. Confirm public MP3 redistribution and game playback rights for the exact recording.
  2. Run the checked-in intake command with the file or folder, exact source, licence and music styles. Add an artist only when the MP3 tags do not provide one.
  3. Open the generated archive pull request. CI verifies the exact bytes, metadata, duplicate hashes and catalogue output.
  4. After merge and Pages deployment, the recording appears here and in the game without copying it into a game release.

Open the complete step-by-step upload guide →

Third-party recordings remain credited to their creators. Public availability is separate from listening approval and from the game’s standard playlists.

Audio uses immutable SHA-256 object paths. The player requests only the chosen recording; it does not download the whole catalogue.
